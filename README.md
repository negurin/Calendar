## ✨ Основные возможности

* **Два режима просмотра:** Год (сетка 3x4 со всеми месяцами) и Месяц (крупный вид одного месяца)
* **Адаптивные шрифты:** Размер текста автоматически подстраивается под размер окна
* **Темная и светлая темы:** Переключение одним нажатием, включая заголовок окна
* **Интуитивная навигация:** Клик по месяцу в году открывает его, клик по большому месяцу возвращает к году
* **Акцент на «Сегодня»:** Текущий день и месяц выделены в любом представлении
* **Быстрый переход:** Кнопка «Сегодня» мгновенно возвращает к текущей дате

## 🛠️ Технологии

* **Язык:** C#
* **Фреймворк:** WPF (Windows Presentation Foundation)
* **Платформа:** .NET Framework 4.8

## 🚀 Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/negurin/Calendar.git
   ```

2. Откройте файл решения (`.sln`) в Visual Studio 2022 или новее

3. Нажмите `F5` для сборки и запуска проекта

## 📖 Использование

- Используйте кнопки **«◀»** и **«▶»** для навигации по периодам

- Кнопка **«Месяц» / «Год»** переключает режим отображения

- Кнопка **«Сегодня»** возвращает к текущей дате

- Кнопка **«🌙» / «☀»** переключает тему оформления
